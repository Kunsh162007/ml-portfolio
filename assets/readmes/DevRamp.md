# 🚀 DevRamp AI — Intelligent Developer Onboarding Platform

> Cut developer onboarding from **months to days** — DevRamp AI analyzes a codebase, generates a personalized learning path, and provides 24/7 AI mentorship.

**Powered by IBM Bob · Built for the IBM Bob Hackathon 2026**

🔗 **[Live Demo](https://dev-ramp-ai.vercel.app/)** · **[GitHub](https://github.com/Kunsh162007/DevRamp-AI)**

---

## 🎯 The Problem

New developers can take **weeks to months** to become productive on an unfamiliar codebase. Onboarding is manual, inconsistent, and pulls senior engineers away from shipping. There's no structured, repo-aware path from "cloned the repo" to "first meaningful commit."

## 💡 The Solution

DevRamp AI turns any repository into a guided, gamified ramp-up:

- **Repo analysis** — connect a Git repository and DevRamp maps its structure, stack, and key modules.
- **Personalized learning path** — generates a step-by-step curriculum tailored to the codebase and the developer's level.
- **AI Mentor** — a 24/7 conversational mentor that answers questions grounded in the actual code.
- **Progress & XP** — learning is tracked with levels, XP, and milestones to keep momentum.

## ✨ Key Features

- **Dashboard** — repositories, learning progress, and activity at a glance.
- **Explorer** — navigate and understand the connected codebase.
- **AI Mentor** — chat-based, context-aware guidance.
- **Learning module** — structured lessons with a per-developer path.
- **Progress tracking** — XP, levels, and completion analytics.

## 🛠️ Tech Stack

- **Frontend:** React 18 + TypeScript, Vite, React Router, Zustand, Tailwind-style design system
- **Backend / API:** Node.js service (proxied at `/api`)
- **AI:** IBM Bob integration for code understanding and mentorship
- **Deploy:** Vercel (frontend) · Railway (API + Bob service)

## 📈 Impact

Built end-to-end as a hackathon submission demonstrating all five IBM Bob capabilities, with a fully responsive UI and a live deployment — targeting the multi-billion-dollar developer-productivity market.
